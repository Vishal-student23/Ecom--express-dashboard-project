
## E-Commerce Sales & Performance Dashboard

## PROJECT OVERVIEW

This project analyzes e-commerce sales data using **Microsoft Power BI** and data visualization techniques. The dashboard provides insights into revenue, orders, products, categories, customer locations, cancellations, and sales trends through interactive visualizations and KPIs.

## Technologies used

Microsoft Power BI • Power Query • DAX • Data Visualization • Data Analysis

## Key Insights

- Revenue and sales performance analysis
- Product and category-wise revenue
- State-wise sales analysis
- Order and Average Order Value (AOV) analysis
- Cancellation rate and lost revenue
- Time-based sales trends
- Interactive filters and dashboard visualizations
